# English на автомате

Личный сайт для изучения английского A2 → B2 → C1: модули дня, грамматика с тестами, интервальное повторение, переписка с вымышленным Mr. X, прогресс.
Сайт: https://firstovempire.github.io/obsession-english/

## Как устроено

```
index.html            каркас, не меняется
engine/               код сайта (ES-модули, без сборки)
  core.js             хранилище, каталог, ленивая загрузка, маршруты, общие функции
  grammar.js          темы, тесты, тренажёр, экзамен
  days.js             модули дня, архив год/месяц/день
  srs.js              повторение фраз
  method.js           план недели, подсказки, система
  progress.js         прогресс
  search.js           поиск
  main.js             главная, настройки/бэкап, меню, запуск
  style.css
content/              учебный материал
  catalog.json        оглавление — ГЕНЕРИРУЕТСЯ, руками не править
  grammar/roadmap.js  дорожная карта тем A1–B2 и список групп
  grammar/<уровень>/<id>.js   тема грамматики
  days/ГГГГ/ММ/ДД.js  модуль дня
  decks/*.js          колоды фраз вне дней
  method/             план недели, подсказки, страница «Система»
  characters/mr-x.md  досье Mr. X
me/progress.js        мои типичные ошибки и срезы (ведёт Claude по отчётам)
me/reports/           отчёты по дням — только локально, в git не попадают
obsession/            выгрузки из Obsession — только локально
backups/              файлы бэкапа прогресса — только локально
tools/build.js        проверка контента + сборка catalog.json
tools/export-old.html перенос прогресса со старой версии сайта
```

## Добавить модуль дня
1. Создать `content/days/ГГГГ/ММ/ДД.js` (формат — как у существующих дней: `export default { id, date, type, title, focus, related, warmup, review, theory, phrases, translate, letter, write, speak, think }`).
2. `node tools/build.js` — проверит и обновит оглавление.
3. Коммит и пуш — через минуту модуль на сайте.

## Добавить тему грамматики
1. Тема должна быть в `content/grammar/roadmap.js`.
2. Создать `content/grammar/<уровень>/<id>.js` с `export default { id, level, group, title, desc, modules: [...] }`.
3. `node tools/build.js`.

## Правила контента (проверяются в build.js)
- Вопросы тестов и предложения перевода **не совпадают** с примерами из теории и фраз: правило то же, материал новый.
- Правильный ответ есть среди вариантов, id уникальны, ссылки `related` ведут в существующие модули.
- Фразы не дублируются между днями и колодами.

## Прогресс
Хранится в браузере (localStorage, ключ `eng-v2`). Раз в неделю: ⚙ → «Сохранить прогресс в файл». На другом устройстве: «Восстановить из файла».

## Локальный запуск
С диска двойным щелчком модули не работают (нужен сервер):
`python -m http.server 8000` в папке проекта → http://localhost:8000
